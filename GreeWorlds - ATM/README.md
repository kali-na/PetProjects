# GreeWorlds Bank — мини-банкомат на Python
login = 'qwerty'
password = 'qwerty'

Консольное приложение, имитирующее работу банкомата: авторизация, управление балансом, переводы и навигация по меню. Проект создан в рамках обучения Python и подготовки к позиции junior-разработчика.

## Возможности

- Авторизация по логину и паролю.
- Просмотр текущего баланса.
- Внесение и снятие средств с базовой валидацией сумм.
- Перевод средств другому пользователю (по ID).
- Выход из сессии и повторный вход без перезапуска программы.

## Стек технологий

- Python 3.x
- Стандартная библиотека (без внешних зависимостей)

## Как запустить

1. Убедитесь, что установлен Python (версии 3.8+).
2. Скачайте или клонируйте репозиторий.
3. Запустите файл: `python main.py`
4. Используйте логин: `qwerty`, пароль: `qwerty`.
