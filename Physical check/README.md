# 🧾 Генератор чека

Консольная программа на Python, которая формирует чек магазина. Пользователь вводит товары, а программа считает сумму по каждой позиции и общий итог и сохраняет результат в текстовый файл.

## Возможности

- ввод названия магазина
- добавление любого количества товаров
- расчёт суммы по каждой позиции (цена × количество)
- расчёт общего итога
- сохранение аккуратно отформатированного чека в `Check.txt`

## Что используется

Проект написан в учебных целях для практики базовых тем Python:

- переменные и типы данных: `str`, `int`, `float`
- списки и словари
- цикл `while` и оператор `break`
- ввод данных через `input()`
- преобразование типов (`int()`, `float()`)
- f-строки и форматирование вывода
- работа с файлами (`with open(...)`)

## Требования

- Python 3.6 или новее
- сторонние библиотеки не нужны

## Запуск

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/название-репозитория.git
   cd название-репозитория
   ```
2. Запустите программу:
   ```bash
   python main.py
   ```
3. Следуйте подсказкам в консоли. Чтобы закончить ввод товаров, введите `СТОП`.

## Пример работы

**Ввод:**

```
Введите название магазина: Продукты
Введите название товара или "СТОП": яблоки
Введите цену товара: 120.5
Введите количество товара: 3
Введите название товара или "СТОП": молоко
Введите цену товара: 85.9
Введите количество товара: 2
Введите название товара или "СТОП": стоп
Чек сохранён в файл Check.txt
```

**Содержимое `Check.txt`:**

```
=============== ЧЕК ===============
Товар                  Цена    Кол-во       Сумма
-----------------------------------------------
яблоки               120.50         3      361.50
молоко                85.90         2      171.80
-----------------------------------------------
ИТОГО: 533.30 руб.
```
