# 🧮 Calculator (Tkinter)

Простой графический калькулятор на Python с использованием библиотеки **Tkinter**.  
Поддерживает базовые арифметические операции, скобки, проценты и десятичные числа.

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

## ✨ Возможности

- ➕ Сложение, вычитание, умножение, деление
- 🔢 Ввод многозначных чисел и десятичных дробей
- 🧩 Поддержка скобок `(` `)`
- 💯 Оператор процента `%`
- 🧹 Кнопка очистки `C`
- 🎨 Простой и понятный интерфейс

---

## 🚀 Запуск

### Требования
- Python 3.7 или выше
- Tkinter (входит в стандартную поставку Python)

> ⚠️ На Linux может потребоваться установить Tkinter отдельно:
> ```bash
> sudo apt-get install python3-tk
> ```
