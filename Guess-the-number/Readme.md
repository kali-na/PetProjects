# 🎯 Guess the Number — "Monica's Game"

Консольная игра на Python: компьютер (Моника) загадывает число, а игрок пытается его угадать за ограниченное число попыток.

---

## 📖 Описание

Игра состоит из **двух уровней**:

| Уровень | Диапазон | Попыток |
|---------|----------|---------|
| 1       | 1–1000   | 15      |
| 2       | 1–1000   | 10      |

На каждом уровне число загадывается **заново** случайным образом.  
Если попытки заканчиваются — игра показывает правильный ответ.

---

## 🚀 Как запустить

1. Установи **Python 3.6+**.
2. Скачай файл `guess_the_number.py`.
3. Открой терминал в папке с файлом и запусти:

```bash
python guess_the_number.py
```

---

## 🎮 Как играть

1. При запуске появится приветствие.
2. Напиши `YES` (регистр не важен: `yes`, `Yes`, ` YES ` тоже подойдут).
3. Вводи числа — игра подсказывает:
   - `No! UP` — загаданное число **больше** твоего.
   - `NO! Down` — загаданное число **меньше** твоего.
   - `YEEEEP! You WIN!` — ты угадал.
4. После победы на уровне 1 начинается уровень 2 с новым числом.
5. Если попытки закончились — игра покажет правильный ответ и завершится.

## 🧠 Логика работы

- Число генерируется через `random.randint(1, 1000)`.
- Попытки считаются счётчиком `attempts_level1` / `attempts_level2`.
- Если игрок вводит не число — программа не тратит попытку и просит ввести снова (`try/except ValueError`).
- Победа/поражение фиксируется через флаги `win_level1` / `win_level2`.
- Ввод `YES` нормализуется через `.strip().upper()`.
