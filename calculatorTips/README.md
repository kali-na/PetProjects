# 💸 Чаевые: «Ресторан на Лавке»

Консольное приложение на Python, которое имитирует оставление чаевых официанту после посещения ресторана. Программа показывает данные чека, предлагает выбрать размер чаевых, проводит (демонстрационную) оплату и сохраняет информацию в текстовый файл.

> ⚠️ **Это учебный проект.** Реальных платежей программа не проводит, номера карт для СБП генерируются случайно.

## Возможности

- Случайно генерируются официант, номер стола и сумма чека.
- Гость может оставить отзыв о визите.
- Размер чаевых на выбор: 10%, 15%, 20%, 25% от суммы чека или своя сумма.
- Два способа оплаты: **СБП** и **банковская карта**.
- Проверка ввода: программа не падает на буквах и пустых строках, а переспрашивает.
- Проверка номера карты (ровно 16 цифр, пробелы игнорируются).
- После успешной оплаты данные дописываются в файл `tips.txt`.

## Требования

- Python 3.6 и новее
- Сторонние библиотеки не нужны (используются только `random`, `datetime` и `pathlib` из стандартной библиотеки)

## Запуск

```bash
python tips.py
```

## Файл с данными

После каждой успешной оплаты в конец файла `tips.txt` (создаётся рядом со скриптом) добавляется запись:

```
Дата и время: 25.11.2026 09:06:34
Ресторан: Ресторан на Лавке
Официант: Оля
Стол: 10
Сумма чека: 3156 руб.
Чаевые: 315.60 руб.
Способ оплаты: СБП
Комментарий: Отлично
----------------------------------------
```

Старые записи не удаляются. **Номер карты в файл не записывается** из соображений безопасности.

## Структура кода

| Функция | Назначение |
|---|---|
| `ask_choice()` | Запрашивает номер пункта меню, пока не будет введён допустимый |
| `ask_amount()` | Запрашивает положительную сумму (допускает копейки и запятую) |
| `ask_card_number()` | Запрашивает и проверяет номер карты (16 цифр) |
| `fake_card_number()` | Генерирует случайный номер карты для СБП (демо) |
| `save_tip()` | Дописывает данные о чаевых в `tips.txt` |
| `pay()` | Единый сценарий оплаты для любой суммы |
| `main()` | Главное меню и логика программы |

## Настройка

В начале файла `tips.py` можно изменить:

```python
RESTAURANT = "Ресторан на Лавке"        # название ресторана
WAITERS = ["Денис", "Оля", "Александра"]  # список официантов
TIP_PERCENTS = (10, 15, 20, 25)          # варианты процентов (меню строится автоматически)
TIPS_FILE = Path(__file__).with_name("tips.txt")  # путь к файлу с данными
```

Например, чтобы добавить вариант в 30%, допишите `30` в `TIP_PERCENTS`, и пункт меню появится сам.
